# Red Store — Plateforme E-Commerce de Sneakers

Projet full-stack MERN (MongoDB, Express, React, Node.js).

## Stack
- Frontend: React 19, Vite, Redux, Tailwind CSS, Framer Motion
- Backend: Node.js, Express, MongoDB/Mongoose
- Images: Cloudinary

## Fonctionnalités
- Authentification JWT
- Panier avec vérification serveur des prix
- Wishlist
- Panel admin (upload produits via Cloudinary)
- Recherche produits

## Installation
### Backend
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`
### Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
